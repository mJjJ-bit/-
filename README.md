# 합성 구조 암기 카드

합성학(유기 합성) 시험 준비용 플래시카드 웹앱입니다. 순수 HTML/CSS/JS로만 되어 있어 인터넷 연결이나 별도 설치 없이 브라우저에서 바로 실행됩니다.

## 사용법

1. `index.html`을 브라우저로 엽니다. (또는 `python3 -m http.server`로 로컬 서버를 띄운 뒤 접속)
2. **카드 관리** 탭에서 구조 이름을 입력하고, 그 아래 캔버스에 정답 구조를 직접 그려서 카드로 저장합니다.
3. **학습** 탭에서 이름만 보고 빈 캔버스에 구조를 그려본 뒤, **정답 보기**를 눌러 저장해둔 정답과 비교합니다.
4. **알았음 / 몰랐음**으로 스스로 체크하면 진행률과 "모르는 카드만" 필터에 반영됩니다.
5. **내보내기 / 가져오기**로 카드 세트를 JSON 파일로 백업하거나 다른 기기와 공유할 수 있습니다.

카드 데이터는 브라우저의 `localStorage`에 저장되므로, 다른 브라우저/기기에서 이어서 쓰려면 내보내기한 JSON을 가져오기 하면 됩니다.
